# CronCompose wiki (in-repo)

This tree is the project wiki: architecture, design decisions, diagrams, and operator
docs. It mirrors the published GitHub wiki.

- **Browse here:** start at [Home.md](Home.md) · [Diagrams.md](Diagrams.md) · [Design-Decisions.md](Design-Decisions.md)
- **Published wiki:** https://github.com/workvar/cron-compose/wiki
- **Assets:** PNG previews in [`diagrams/`](diagrams/); interactive Archify HTML in [`html/`](html/)

Pages use standard Markdown links (`[Label](Page.md)`) so Jumpstart, GitHub file
browse, and the published wiki all resolve them.

Specs that stay closer to the code also live as plain docs beside this folder
([`docs/architecture.md`](../architecture.md), etc.). Prefer this wiki for the curated
narrative and diagrams; prefer `docs/*.md` when editing the canonical engineering specs.
